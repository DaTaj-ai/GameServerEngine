## Introduction
**GameServerEngine** is a server application built in Java, designed to manage game logic, player interactions, and data synchronization. This server integrates a SQLite database for persistent storage and supports network communication with a client application, which can be found in a separate repository.

## Features
- **Game Logic Management**: Handles core game mechanics and rules.
- **Player Interaction Handling**: Manages player inputs and interactions.
- **Data Synchronization**: Ensures consistent game state across all clients.
- **SQLite Integration**: Provides persistent data storage.
- **Network Communication**: Facilitates seamless communication with client applications.
